# 0002 — 脚本合并与步骤号前缀约定

- 状态：已接受（2026-10-06）
- 关联：[CONTEXT.md](../../CONTEXT.md)（步骤号（前缀号）词条）、[0001](0001-no-orchestrator.md)（自包含脚本的交付形态）

## 背景

ADR-0001 定下「raw 单文件交付 → 脚本必须自包含 → 公共逻辑只能内联」之后，代价落在两处：每个脚本各带一份公共块拷贝（实测 570 行公共函数 + 每脚本约 25 行头部，约占仓库体积 18%），以及相邻步骤之间的语义耦合只能靠「人按顺序执行 + 跨脚本前置自检」维持。

2026-10-06 复盘合并候选，按**跨脚本语义耦合度**（而非主题相似度）筛出两组：

- `01-update.sh` + `02-tools.sh`：同属 apt 系统准备，相邻步骤、中间无闸门、均幂等；合并后少一次 raw 拉取（新机器少一次网络往返，对大陆访问 GitHub 的场景是实打实的）。
- `05-ufw.sh` + `06-ssh.sh`：共享 `SSH_PORT`/`OLD_SSH_PORT`；`06` 的前置自检就是「检查 `05` 干完没有」；两者各有一套 ufw 规则查询实现（`05` 的 `fw_has_rule` 在 ufw 未启用时回退查 `ufw show added`，`06` 的 `ufw_has` 只读 `ufw status`）。

`07-fail2ban.sh`、`08-swap.sh`、`09-bbr.sh`、`12-verify.sh` 不在合并范围：`07` 是 fail-closed 自检独立的子系统、锁死风险为零，`08` 自带 helper 体系且有意不开 `-e`，`12` 是 fail-closed 的第二意见、必须能独立重跑，`09` 与 `08` 只是主题相近、子系统无关。

## 决策

1. **合并两组**：`01-update.sh` + `02-tools.sh` → `01-base.sh`；`05-ufw.sh` + `06-ssh.sh` → `05-ufw-ssh.sh`。其余脚本保持独立。
2. **步骤号不重排**：合并后的脚本以起始步骤号命名、覆盖一个区间（README 写「1–2」「5–6」），其余步骤号与文档引用一字不动。
3. **不保留旧文件名的转发壳**：测试阶段、无分发，重命名即断链。
4. **仍不做公共块生成器**（见「被否的替代方案」第 1 条）。
5. 合并后的脚本保持 `CONTEXT.md` 的「维护菜单」形态：编号操作项、一次只做一件事；两个只读项（ufw 规则详情、sshd 生效状态）合成一项「状态总览」。

## 被否的替代方案

1. **生成器**（`lib/common.sh` + `tools/build.sh` 产出各脚本）：能把重复归零，产物仍是自包含单文件、交付形态不变，且 `sync_check` 的函数比对会变成多余。否决理由：仓库多一个构建步骤，且从此不能直接手改脚本（改了会被下次生成覆盖）；本仓库没有 CI、没有 pre-commit，`build --check` 只能靠自觉，等于新增「忘了跑 build」的失败模式。它的收益集中在「频繁批量改公共层」，而这套脚本的日常改动是「改某一个脚本里的一段」。**触发重评的条件**：公共块改动变得频繁，或需要批量统一输出风格。
2. **全量重编步骤号**（1 系统准备 / 2 基础配置 / … 连续）：编号连续漂亮，但 README 16 行 raw/加速 URL、教程 6 处引用与 14 个章节标题、锚点 `docs/tutorial.md#11-docker提示`、`sync_check`、`CONTEXT.md`、`.omp/AGENTS.md` 全部要动，漏一处就是死链。区间标注的改动面小一个量级。
3. **合并后留空号**（不再有 `02`/`06` 文件）：会把既有「跳号 = 手动步骤」的约定变成两义。
4. **`07` 并入 `05+06` 三合一**：只省约 86 行，却把锁死风险为零的 fail2ban 并进唯一能锁死人的文件，稀释「改这个文件必须走真机闸门」的信号。

## 后果

- `01-base.sh` 覆盖步骤 1–2，`05-ufw-ssh.sh` 覆盖步骤 5–6；其余脚本仍与步骤号一一对应。`01-base.sh` 的执行顺序改为「升级 → 装工具 → 最后才问重启」，一次人工往返收尾。
- `05-ufw-ssh.sh` 是仓库里**唯一能锁死登录**的文件（防火墙放行 + sshd 端口迁移 + 双闸门），改动必须真机全链路验收：两次闸门确认 + 新终端密钥登录 + `12-verify.sh` 全绿。
- 合并减少的是**公共块拷贝份数**（8 → 6），不是重复本身；重复的根因仍是 ADR-0001 的内联要求。
- 跨文件指向改为脚本内导航：`05-ufw-ssh.sh` 的前置自检不再提示「请先运行 05-ufw.sh」，而是「请先在主菜单选 1) 初始化防火墙」；判断条件与闸门文案保持不变。
